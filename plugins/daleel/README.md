# Daleel Claude plugin

Skills for working on this app with Claude Code:

- `add-attraction`: add or edit places in `assets/data/attractions.json`
- `add-strings`: add English and Arabic text to `lib/strings.dart`
- `check-data`: run `scripts/check_data.py` to validate data, images, RAG index links and string parity

Install:

```
/plugin marketplace add SaraAlMessabie/Daleel-Al-Ain-Tourism-App-
/plugin install daleel@daleel
```
